# Desenvolvimento por etapas

Diagnóstico inicial: repositório clonado, main limpa, arquivo RPG_Game/main.py vazio; nenhuma suíte de testes. Executá-lo não produzia saída. Após criar o ambiente, pytest informou “no tests ran”.

Etapa 0 prepara src/main.py, mapa, personagem e testes iniciais. Em seguida, as 15 ações do chat serão implementadas na ordem, uma issue, branch e PR por entrega. Cada branch parte da main atualizada. PRs usam Closes com o número real da issue.

As ações 13 e 14 ampliam as suítes; testes básicos acompanham cada funcionalidade desde o início, conforme o roteiro mais recente.

Exceção autorizada pelo proprietário: trabalho individual, sem revisor independente nem autoaprovação. Integração após verificação automatizada.
